# تشغيل Brave المخفي

تستخدم الأداة **Brave في وضع headless**: لا نوافذ، ولا تبويبات في متصفحك الشخصي، ولا تحكم بالفأرة أو لوحة المفاتيح. ملفها المستقل الافتراضي هو `%LOCALAPPDATA%/SimsimaAgent/Brave`. لا تشغّلها على ملف Brave الشخصي؛ يرفض الإعداد ذلك لمنع قفل الملف والتعارض.

## التجهيز مرة واحدة

لنقل حساب X المفتوح بالفعل، يستعمل `npm run session` اتصال CDP محليًا بالمتصفح الشخصي. يقرأ جلسة X فقط وينقلها في الذاكرة مباشرة إلى ملف الأداة، ثم يفحص الحساب داخل Brave المخفي. لا ينشئ تبويبات في المتصفح المصدر، ولا يحفظ ملف cookies بصيغة JSON، ولا ينسخ ملف المتصفح.

إذا كان اتصال المصدر غير متاح، يلزم فتح Brave الشخصي مع الاتصال المحلي مرة واحدة فقط: احفظ عملك واختر Exit من قائمته، ثم شغّل `npm run brave`. يرفض المشغّل إغلاق المتصفح بالنيابة عنك. بعدها شغّل `npm run session` ثم `npm run account`.

إذا منع إصدار Brave أو سياسة الجهاز اتصال CDP بملفه الشخصي، يلزم تجهيز تسجيل الدخول مباشرة في ملف الأداة بدلًا من نقل الجلسة. لا تحاول الأداة تجاوز ذلك أو استخراج كلمات المرور.

## الاستخدام اليومي

بعد نجاح التجهيز، لا يتطلب النشر وجود متصفحك الشخصي مفتوحًا أو منفذ CDP فيه. تعمل الأداة في متصفح مخفي مستقل وتغلق عمليتها بعد المهمة، مع حفظ تسجيل الدخول في ملفها الخاص. يمكنك مواصلة عملك على الجهاز كالمعتاد.

عند انتهاء تسجيل الدخول أعد `npm run session` من جلسة X المسجلة لديك. لا تُنشر المسودة إذا تعذر التحقق من الحساب.

## جلسة YouTube

شغّل `npm run youtube-session` لنقل تسجيل دخول YouTube فقط بالطريقة نفسها، ثم `npm run youtube-account` للتحقق من القناة. لا ينقل الإعداد ملفات تعريف المتصفح أو بيانات Gmail، ولا يغيّر جلسة X المحفوظة. يُستخدم معرّف القناة الدائم في المسودات حتى تتوقف العملية إذا اختلفت القناة النشطة.
