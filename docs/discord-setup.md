# ربط قناة Discord مرة واحدة

الإضافة الحالية تنشر نصًا حتى 2000 حرف مع صورة PNG/JPEG واحدة اختيارية حتى 5 MiB في قناة نصية محددة عبر Incoming Webhook. تعمل عبر HTTP مباشرة دون Brave أو بوت أو مفتاح نموذج. منشورات قنوات المنتدى والخيوط خارج نطاق هذه النسخة.

## الإعداد

1. في Discord افتح إعدادات السيرفر ← **Integrations** ← **Webhooks** ← **New Webhook**. يتطلب إنشاؤه صلاحية إدارة Webhooks.
2. اختر القناة النصية المقصودة، واضبط اسم Webhook وصورته إن أردت، ثم احفظ وانسخ الرابط.
3. ضع الرابط محليًا في `.data/discord.json`:

   ```json
   {
     "webhook_url": "ضع رابط Webhook هنا"
   }
   ```

   الملف مستبعد من Git. الرابط يتضمن رمز النشر؛ لا ترسله في المحادثة ولا تضعه في ملفات التوثيق. يمكن بدل الملف استخدام متغير البيئة `SIMSIMA_DISCORD_WEBHOOK_URL`. تغيير الملف يُقرأ في الطلب التالي دون إعادة تشغيل الخدمة.
4. نفّذ `node src/cli.js discord-status` أو أداة `discord_status`. النتيجة تعرض `channel_id` و`guild_id` ورابط القناة دون الرمز. احفظ الوجهة المعتمدة لتستخدمها في المسودات التالية.
5. عندما يطلب المستخدم النشر، اتبع [دليل النشر](PUBLISHING.md): `discord_prepare_post` ثم `discord_publish_prepared_post` مرة واحدة. نجاح الإعداد وحده ليس طلبًا لإرسال رسالة اختبار.

مرجع إنشاء Webhook: [دليل Discord الرسمي](https://support.discord.com/hc/en-us/articles/228383668-Intro-to-Webhooks).

## ما ينفذه الناشر

يتحقق من أن Webhook يشير إلى قناة المسودة، ثم يرسل طلبًا واحدًا مع `wait=true` ليحصل على معرّف الرسالة. يقرأ الرسالة بعدها عبر Webhook للتحقق من النص والقناة واسم الصورة وحجمها ونوعها، ويعيد رابطًا بالشكل `https://discord.com/channels/GUILD/CHANNEL/MESSAGE`.

تُرفع نسخة الصورة المحفوظة في المسودة. تطابق بيانات المرفق لا يعني إعادة تنزيله لمقارنة بصمته. تبقى تنبيهات الإشارات مثل `@everyone` معطّلة في هذه النسخة.

لا يعيد الناشر POST تلقائيًا. رفض HTTP الصريح مثل 400 أو 429 يُسجل `failed`، ويعرض مدة الانتظار عند توفرها. انقطاع الاتصال أو خطأ خادم بعد بدء الإرسال يُسجل `uncertain`. إذا حُفظ معرّف الرسالة، يمكن قراءتها باستخدام `discord_get_operation` مع `verify: true` أو CLI `verify` دون إرسال جديد. إن لم يُحفظ معرّف، تبقى الحالة غير محسومة.

توثيق الواجهات: [Webhook Resource في Discord](https://docs.discord.com/developers/resources/webhook).
